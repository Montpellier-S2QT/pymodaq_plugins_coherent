Installation instructions
=========================

* Tested on PyMoDAQ v5.2.0a1
* Tested on a computer operating on Windows 11
* This plugin requires the NI VISA communication library. You can download it on the NI official website: https://www.ni.com/fr/support/downloads/drivers/download.ni-visa.html
